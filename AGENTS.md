# AGENTS.md

Repoet inneholder felles retningslinjer som vanlig Markdown. Det finnes ingen kode å bygge.

## Regler

- Retningslinjene skal være generelle: ingen navn på bestemte organisasjoner, domener, personer eller tjenester utover
  eksempler. Det som gjelder ett repo, står i det repoet.
- Følg [documentation.md](documentation.md) og [naming.md](naming.md) også her.
- Alle endringer går via pull request med grønne sjekker.
